## Claude Code

Claude Code nenačítá `.agents/skills/` automaticky. Když úloha odpovídá některému skillu z mapy výše, otevři jeho `SKILL.md` ručně a postupuj podle něj; reference a šablony skillu čti relativně k jeho složce.

Globálně nainstalovaný plugin `diagram-design` může mít jinou verzi než přibalená kopie. V Documentoid se řiď kopií v `.agents/skills/diagram-design/`, protože na její skripty odkazují npm příkazy.
